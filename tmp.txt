    information theoretic general:

    Although the example assumes that values are updated by sample averages, the argument could be generalised to any way that the point estimate is updated by an information theoretic argument. Informally, a single vector cannot carry the information of an entire set of values that can be obtained by an undominated set of policies (Definition \ref{def:2:undominated_set}).
